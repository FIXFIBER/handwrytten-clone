TOP10 NG — Open-Source Animation Sample

Everything below uses FREE, open-source libraries & assets (MIT / CC0 / open). No Handwrytten art. This is a live demo of what these tools can do together for the TOP10 NG brand.

Lottie

Friendly Robot

Vector animation rendered by lottie-web (MIT). Great for hero characters, loaders, mascots.

lottiefiles.com
Lottie

Rating Star

airbnb/lottie-web
Lordicon

Animated Icon

@lordicon/element player is installed — drop any Lordicon .json in and it animates. Sample above is an inline fallback.

lordicon.com
unDraw

Scene Illustration

Inline SVG you recolor to brand. MIT license — use anywhere, edit freely.

undraw.co
Humaaans

People Mix

Hand-drawn people, MIT — remix bodies/poses for testimonials & communities.

humaaans.com

Hand Doodle
